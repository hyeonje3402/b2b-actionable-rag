# 개선 로드맵 제안

[메인 README](../../README.md)

현재 저장소에는 제품 패키지 버전이나 릴리스 태그가 보이지 않습니다. 아래는 출시 약속이 아닌 개발 마일스톤 제안입니다.

## 다음 마일스톤 제안 — v0.2.0: 신뢰 가능한 문서 Q&A

- 코드와 일치하도록 Gemini 환경 변수 예시를 정리
- 업로드 파일명 충돌·삭제·재색인 오류 처리와 파일 크기 제한 추가
- 검색 근거가 부족할 때 답변 보류와 출처 범위 검증 강화
- 문서별 처리 상태, 색인 결과, 오류 사유를 UI에서 확인
- 문서 파싱·청킹·검색 API 자동 테스트 추가
- 로컬 경로를 설정 가능하게 하고 운영 데이터 영속성 설계

## 다음 후보 — v0.3.0: 안전한 업무 액션

- 샘플 휴가 기안 함수를 실제 승인된 API와 연결할 때 사용자 인증과 확인 단계를 적용
- 다중 조직 권한, 액션 감사 기록, 중복 제출 방지 구축
- 문서·대화 데이터의 보유 기간과 개인정보 삭제 흐름 구현

## 현재 한계

ChromaDB와 SQLite는 로컬 파일에 저장됩니다. 운영 다중 인스턴스 배포, 백업, 접근 제어와 그룹웨어 연동은 현재 구현 범위에 포함되지 않습니다.
