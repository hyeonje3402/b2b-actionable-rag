# 운영·연동 경계

[메인 README](../../README.md)

## 현재 운영 형태

저장소 설정은 로컬 개발 실행에 초점이 맞춰져 있습니다. FastAPI CORS 허용 주소는 localhost 프런트엔드 포트로 제한되어 있고, ChromaDB와 SQLite 메트릭 파일은 로컬 디스크에 저장됩니다. Docker, CI workflow, 클라우드 배포, 외부 운영 DB 설정은 확인되지 않았습니다.

## 실제 서비스 이전 전 필요한 작업

- 프런트엔드와 백엔드 도메인에 맞는 CORS·TLS·인증 설정
- 영구 파일 스토리지와 백업·복구 전략
- 다중 사용자·다중 조직별 문서 권한과 색인 분리
- 업로드 파일 크기·악성 파일 검사, 문서 삭제 시 벡터 청크 동기화
- ChromaDB와 메트릭 저장소의 운영 환경 선택
- API 키·로그·문서 개인정보 접근 정책 마련
- CI에서 백엔드와 프런트엔드 빌드·테스트 자동 실행

## 데모 기능 표시

전자결재 함수는 현재 랜덤 문서번호와 예시 인적사항을 만들어 응답합니다. 실제 그룹웨어 결재 결과로 오해하지 않도록 UI와 문서에 데모임을 표시하고, 운영 연동 전 승인·중복 제출 방지·감사 로그를 구현해야 합니다.
